# Instruction Manager

Полноценное веб-приложение для управления инструкциями с современным интерфейсом.

## 🚀 Быстрый старт

1. Скачайте все файлы
2. Запустите `index.html` в браузере
3. Используйте credentials:
   - Login: `testuser`
   - Password: `testuser2025`

## 📁 Структура проекта

instruction-manager/
├── index.html          # Главная страница
├── css/
│   └── styles.css      # Стили
├── js/
│   ├── app.js          # Главный модуль приложения
│   ├── auth.js         # Аутентификация
│   ├── storage.js      # Работа с LocalStorage
│   ├── ui.js           # Управление интерфейсом
│   └── editor.js       # Редактор инструкций
└── README.md           # Документация



## ✨ Функции

- **Авторизация**: Безопасный вход с тестовыми данными
- **Управление группами**: Создание, редактирование, удаление
- **Управление инструкциями**: Полный CRUD с пошаговым редактором
- **Редактор**: 
  - Добавление/удаление шагов
  - Перемещение шагов
  - Загрузка изображений
  - WYSIWYG контент
- **Адаптивность**: Mobile-first дизайн
- **Modern UX**: Современный интерфейс с плавными анимациями

## 🛠️ Технологии

- **Frontend**: Чистый HTML5, CSS3, JavaScript (ES6 Modules)
- **Storage**: LocalStorage API
- **Design**: CSS Grid, Flexbox, CSS Variables
- **No Backend**: Полностью клиентское приложение

## 📱 Адаптивность

- Desktop: 280px sidebar + основной контент
- Tablet: Адаптивная верстка
- Mobile: Выдвижное боковое меню
