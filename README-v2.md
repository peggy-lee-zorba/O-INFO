# O-INFO v2.0 - Система управления инструкциями с файловой системой

## 🎯 Что было улучшено

### 📁 Новая система хранения
- **Файловая система**: Инструкции теперь хранятся как отдельные HTML файлы в папке `instructions/`
- **Галерея изображений**: Изображения сохраняются в папке `images/`
- **Fallback режим**: При недоступности File System Access API используется LocalStorage

### 🎨 Новый интерфейс
- **Современный дизайн**: Обновленные стили с использованием CSS переменных
- **Панель инструментов**: Новые кнопки для работы с изображениями, статистикой и экспортом
- **Поиск**: Реальный поиск по названию и содержимому инструкций
- **Система уведомлений**: Красивые toast-уведомления о действиях

### 📊 Новые возможности
- **Статистика**: Отображение количества инструкций, групп, изображений
- **Экспорт данных**: Скачивание резервной копии всех данных
- **Галерея изображений**: Управление изображениями с возможностью вставки в инструкции
- **Улучшенный редактор**: Валидация, предварительный просмотр, горячие клавиши

## 🚀 Как использовать

### Основные действия

1. **Авторизация**
   - Логин: `testuser`
   - Пароль: `testuser2025`

2. **Создание групп**
   - Кнопка "+ Новая группа" в боковой панели

3. **Создание инструкций**
   - Кнопка "📝 Новая инструкция" в верхней панели
   - Введите название и HTML содержимое
   - Используйте "👁️ Предварительный просмотр" для проверки

4. **Загрузка HTML файлов**
   - Кнопка "📁 HTML" в редакторе
   - Поддерживаются файлы .html и .htm

5. **Работа с изображениями**
   - Кнопка "🖼️ Изображения" для открытия галереи
   - Загрузка изображений через "📁 Загрузить изображение"
   - Вставка изображений в инструкции через "📎"

6. **Поиск**
   - Поле поиска в верхней части списка инструкций
   - Поиск по названию и содержимому

### Сохранение в файлы

#### Если поддерживается File System Access API:
1. Браузер запросит разрешение на доступ к файловой системе
2. Выберите папку для хранения данных O-INFO
3. Инструкции будут сохранены в `инструкции/instr-{timestamp}.html`
4. Изображения будут сохранены в `изображения/img-{timestamp}-{filename}`

#### Fallback режим (LocalStorage):
- Если File System Access API недоступен, данные сохраняются в LocalStorage браузера
- Все функции работают аналогично, но данные не сохраняются в файлы

### Экспорт данных

1. Нажмите кнопку "💾 Экспорт"
2. Скачается JSON файл с резервной копией всех данных
3. Включает информацию об инструкциях, изображениях и настройках

### Браузерная поддержка

- **File System Access API**: Chrome 86+, Edge 86+
- **Fallback режим**: Все современные браузеры
- **Рекомендуется**: Chrome или Edge для полной функциональности

### Режимы работы

1. **Файловая система** (предпочтительный)
   - Реальные файлы на диске
   - Сохраняются при закрытии браузера
   - Доступ к файлам извне приложения

2. **LocalStorage** (fallback)
   - Данные в браузере
   - Очищаются при очистке данных браузера
   - Подходит для тестирования

## ⚠️ Важные замечания

### Безопасность
- При использовании файловой системы, выберите папку, к которой у вас есть права доступа
- Не размещайте чувствительные данные в общих папках

### Производительность
- Большое количество изображений может замедлить работу
- Рекомендуется оптимизировать изображения перед загрузкой

### Совместимость
- При переносе на другой компьютер скопируйте всю папку с файлами
- Данные LocalStorage не переносятся между устройствами
